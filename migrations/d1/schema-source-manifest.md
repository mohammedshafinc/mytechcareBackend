# D1 schema source manifest

`0001_fresh_schema.sql` is the fresh-database replacement for all 23 TypeORM entities. There is intentionally no RDS import. `tests/integration/d1/schema-contract.test.ts` introspects every table and exact column list, representative foreign keys, required indexes/triggers, seed counts, and `PRAGMA foreign_key_check`.

## D1-only tables and integrity matrix

| Table | Purpose and integrity owner |
|---|---|
| `role_modules` | Fail-closed role fallback; `(role,module_code)` PK and module FK. Seed intentionally has zero policy rows. |
| `number_counters` | Atomic scoped visible-number allocation for requests/documents/stores/staff; store/staff floor triggers prevent reuse after manual matching codes. |
| `invoice_chain_state` | Singleton optimistic chain owner; guard/insert/update/delete triggers keep latest ownership coherent. |
| `notifications` | Unique idempotency `source_key`, checked type/JSON, indexed type+cursor. |
| `notification_recipients` | Publication-fixed admin recipients; composite PK, two cascading FKs, poll and unread indexes. |
| `scheduled_runs` | Riyadh-date lease, attempt token/state/count, completion/failure metadata, lease index. |
| `bootstrap_state` | One-time singleton linked to a non-deletable initial administrator. |
| `auth_rate_limits` | HMAC-only fixed-window key, composite PK, bounded cleanup index. |

## Foreign keys, triggers, indexes, and type conversion

Declared delete behavior is retained: permission/item/recipient children cascade; admin/store/document links use the entity-declared `RESTRICT`, `SET NULL`, or `CASCADE`; polymorphic enquiry parents are validated and cascaded by four triggers because SQLite cannot express a polymorphic FK. Service-request notification publication and recipient materialization are trigger-atomic. Invoice-chain ownership and counter floors are trigger-atomic.

All nine indexes from `migrations/add_staff_extended_fields.sql` are translated: employee status, email, primary mobile, visa, insurance, iqama, passport and driving-license expiry, and date of joining. PostgreSQL comments/PLpgSQL are intentionally omitted. Route, FK, report, polling, lease, and cleanup predicates have explicit indexes in `0001_fresh_schema.sql`.

Money is integer halalas, odometers are integer tenths, VAT rates are basis points, and booleans are checked integers. DATE is exactly ten ASCII-shaped bytes and TS is canonical 24-byte UTC text; service validation additionally owns Gregorian calendar semantics. IDs remain stable `INTEGER PRIMARY KEY AUTOINCREMENT` where source entities generated IDs.
